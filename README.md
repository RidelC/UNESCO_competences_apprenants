# Référentiel UNESCO de compétences en IA pour les apprenants
L'UNESCO a publié un référentiel de compétences en IA pour les apprenants : https://www.unesco.org/fr/articles/referentiel-de-competences-en-ia-pour-les-apprenants
Il s'organise en 4 axes et 3 niveaux de maîtrise
# Un outil pour naviguer
Ce fichier permet de naviguer plus aisément dans tous les blocs de compétences
